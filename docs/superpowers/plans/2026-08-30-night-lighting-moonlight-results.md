## 3. 「月光主导」量化锚（spec §8 满月 vs 新月）

- 显示域满月月光增量：+31.95；新月夜底光基线画面均值：46.01 → **增量/基线 = 0.69**（满月云区画面比底光画面亮 69%）
- 月光增量占满月云区画面亮度：31.95/77.96 = **41%**（底光仍占 59%）
- spec 锚「月光 irradiance ≥ 1.5×nightAmbient」是**线性 irradiance 域**的量；显示域经 ACES+gamma 对暗部有提升增益，两域不可直接换算（显示域 0.69 与线性域 1.5 不矛盾也无法互推）。
- **结论：口径受限，如实记录待拍板**——显示域月光增量显著（+69%）但未过半主导；moonLightScale=50000 默认值观感需用户视觉拍板（spec §9 既定流程：过暗优先调 moonLightScale，nightAmbient 兜底不动）。

## 4. 偏差与归因记录

### 4.1 满月「月相可辨」幅度
ε=177.1° 近望，物理月相缺口面积极小（照明面积 99.9%），盘内明暗分布 62-98（std 8.5）——「非均匀」判据字面过，但视觉上是**近全圆的均匀暖灰盘**，月相缺月不可辨。这是该日期的物理正确表现，非渲染缺陷；若要明显月相形态需选 ε 更偏离 180° 的日期验收。

### 4.2 新月夜全图残差场（8s 等待所致）
云区（判据 ROI，357,673 像素）逐像素精确零；全图（HUD 外 712,598 像素）另有 diff≥1 的残差 5,269 像素（占 0.74%；终审修复轮 node+pngjs 重核：分档计数逐档吻合，总数 5,269——原「5,261」系误记的前四档之和），**全部位于上部天空区（y<288）**：=1 级 2,358 / 2-3 级 1,382 / 4-7 级 1,073 / 8-15 级 448 / ≥16 级 8 像素（两小簇 @(181-185,128-129)、@(169,129)，另 @(438,109)、@(75,141)），meanAbsLumDiff=0.0129。差异点方向与月方向（el −11.9°/az 274°）差 100°+，非月盘/月光；归因 8s 等待下两次加载的场景静止残差（后续 G4/G5 经 ≥15s 纪律重拍均获全图逐像素精确零，佐证残差随稳定时间消除）。

### 4.3 弦月/满月增亮比 0.474 高于物理比 0.304
物理月光 irradiance 比 = f_qtr/f_full = 0.297/0.976 = 0.304；显示域 Δ 比 = 15.16/31.95 = 0.474（判据带 [0.167,0.5] 内、压上限）。归因：① tonemap 非线性（增量落在曲线斜率更高段）；② 两组日期相隔 11 天，云量分布不同（Δ 是云区均值，云形态差异混入）；③ 底光分量在两组中不同（ moon=0 基线 46.01 vs 39.94，当日云量不同所致，同源②）。

### 4.4 录制纪律事故两例（非月光 bug，均已重拍解决）
- G4 首拍：moon-on 截图撞 563.9ms/0FPS 卡顿帧，场景未稳定（地表纹理未加载、云未收敛、attribution 条缺失）→ 成对 diff 出 −5.95 假警报；15s 等待重拍后逐像素精确零。
- G5 首拍（8s 等待）：云区弥散 diff（max 44，diff>10 像素 10.4 万个）→ 20s 等待重拍后全图逐像素精确零。**成对录制等待须 ≥15s，以重拍结果为准**。

## 6. 月光成本实测与终审补证（终审修复轮，2026-08-30）

方法：起服前清 vite 缓存；agent-browser headless 每组独立 session + close 重开、≥18s 稳定等待；整帧指标读 Cesium 自带 FPS 框（`debugShowFramesPerSecond`，右上角，5× 裁剪放大截图三帧交叉读数）；逐 stage GPU 计时用 `?profile=1`（EXT_disjoint_timer_query_webgl2，console 每 60 帧 JSON，末 N 行中位数）。

### 6.1 FPS 成对实测（白天 + ultra 档，终审 Important 1）

URL：`?mode=atmosphere&clouds=1&cloudsQuality=ultra&time=2026-08-30T04:00:00Z&camera=103.8929,16.5428,3106,59.3,-11.9&profile=1`，moon 开 vs `&moon=0` 各自独立 session：

| 侧 | ms/帧（3 帧读数） | FPS（3 帧读数） |
|---|---|---|
| moon 开 | 16.78 / 16.72 / 16.71 | 60 / 59 / 60 |
| moon=0 | 17.33 / 16.82 / 16.51 | 59 / 58 / 60 |

结论：**无感**——两侧均 vsync 60fps 锁顶，ms/帧差异在帧间抖动内（moon=0 侧均值反而高 0.15ms）；与物理预期一致（`moon=0` 仅 uniform 置零/关分支，不增删 pass 与采样）。GPU 键级中位数：atmosphere 13.53（开）vs 13.66ms（关）、clouds_overlay 13.12 vs 13.10ms——同分布无差。口径注：本环境（headless + 每帧 18 个 query）timer 读数存在查询排队伪影（lf 链逐键呈阶梯状、逐行全键加总中位数 100ms+ 明显失真），故 GPU 计时只取「同伪影下的两侧键级中位数差分」用于开/关对比，**不作为绝对成本数据**；整帧结论以 FPS 框为准。

### 6.2 k² 补偿路径视觉证据（满月盘 ×4.44 放大，终审 Important 2①）

同 time（2026-09-25T16:00Z）同月盘镜头（`camera=103.8929,16.5428,3106,176.5,60`），默认 ω=0.0045 vs `?moonAngularRadius=0.02`（×4.44），各自独立 session：

| 项 | 默认 ω=0.0045 | ω=0.02（×4.44） |
|---|---|---|
| 盘径 | 8.8px | 43.8px（理论 0.04 rad @ 577px/60° fov → 44px） |
| 盘内均值（>50% 盘心亮区） | 87.0 | 87.6（**+0.7%**） |
